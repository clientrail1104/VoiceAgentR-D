5 Lines of Code to Initiate a Phone Call

Deploy an agent using REST API, Node.js SDK, or Python.

curl -X POST https://api.omnivoice.ai/v1/calls/dispatch \
  -H "Authorization: Bearer omni_sk_live_99283719" \
  -H "Content-Type: application/json" \
  -d '{
    "phone_number": "+14155552671",
    "agent_id": "ag_sales_sarah",
    "stt_provider": "deepgram",
    "llm_model": "gpt-4o-mini",
    "tts_provider": "elevenlabs",
    "variables": { "customer_name": "Alex" }
  }'
